## Usage

These are standalone contest programs, not a single application. Check the corresponding problem PDF for input/output formats and constraints.

```bash
python lambad.py
```

**Note:** `kanal.py` uses an interactive encoding/decoding protocol; it cannot be tested like a normal static-input script without an appropriate interaction harness.

## Scope

This repository preserves contest work. It does not claim that every solution is complete, accepted, or optimal. No automated correctness verification is provided here. Problem statements are included for context; their authorship is separate from the solutions.
